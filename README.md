# がっこう手帳

中学生のための「時間割・持ち物・提出物・テスト」管理アプリです。
スマホのブラウザで開いて、ホーム画面に追加するとアプリのように使えます（オフラインでも動きます）。

## できること

| タブ | 内容 |
| --- | --- |
| 🏠 今日 | 今日の時間割 / **次の登校日の持ち物チェックリスト**（時間割から自動作成） / 1週間以内の提出物 / 次のテストまでの日数 |
| 🗓️ 時間割 | マスをタップして教科を選ぶだけで登録 |
| 📝 提出物 | しめきり順に表示。「明日」「あと3日」「◯日すぎてる」がひと目でわかる |
| ✏️ テスト勉強 | テストまでのカウントダウン / **勉強計画**（やることを書くとテスト前日まで自動で割り振り） / **勉強タイマー**と勉強時間グラフ / **点数の記録**と前回比 |
| ⚙️ 設定 | 教科ごとの持ち物、毎日の持ち物、土曜授業、時間数、祝日・休校日、データの書き出し/読み込み |

- 持ち物リスト = 毎日の持ち物 ＋ 時間割の教科の持ち物 ＋ その日しめきりの提出物 ＋ その日だけの持ち物
- データはその端末のブラウザ内（localStorage）だけに保存され、外部に送信されません
- 機種変更のときは「設定 → 書き出す」で保存したファイルを新しい端末で「読み込む」

## テスト勉強の流れ

1. 「テスト勉強」タブの＋でテストを登録（日にち・教科・範囲）
2. 「まとめて計画を作る」で教科ごとにやることを1行ずつ書く → 今日〜テスト前日に均等に割り振られる
3. 毎日「今日」タブに出てくる“今日やること”にチェック。遅れているものは「◯日おくれ」と表示
4. 勉強するときはタイマーをスタート（アプリを閉じても計り続ける）。25分ごとに休憩の声かけ
5. テストが終わったら点数（と平均点）を入力 → 前回からの上がり下がりがわかる

## 使い方（公開）

ビルド不要の静的ファイルだけでできています。GitHub Pages で公開するのがかんたんです。

1. GitHub のリポジトリ → **Settings → Pages**
2. Source を「Deploy from a branch」、ブランチとフォルダ（`/ (root)`）を選んで保存
3. 表示された URL をスマホで開き、共有メニューから「ホーム画面に追加」

手元で試すとき:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## ファイル構成

- `index.html` — 画面の枠
- `style.css` — デザイン（ダークモード対応）
- `app.js` — アプリ本体
- `manifest.json`, `icon.svg`, `sw.js` — ホーム画面追加・オフライン対応
